# アーキテクチャ

## 1. 方針

MVPは「URLまたはローカルリポジトリを開く → ツリーから選ぶ → 写経する →
完了が保存される」という1本の体験を完成させます。機能別に実装を分担しますが、
途中成果を個別リリースする前提にはしません。

設計上の原則は次のとおりです。

- ドメインロジックをTUI、SQLite、ファイルシステムから独立させる。
- UIは状態を描画し、入力をアプリケーションコマンドへ変換するだけにする。
- ファイル完了やディレクトリ進捗は、完了ファイルの正規化済み行数から導出する。
- ファイル全体の正規化済み本文ハッシュを、再走査後の進捗照合に使う。
- 外部通信はシステム`git`によるcloneだけに限定する。
- ユーザー入力をシェルへ渡さず、`git`には個別の引数として渡す。
- 端末状態は正常終了、中断、エラーのすべてで確実に復元する。

## 2. モジュール

```text
src/
  main.rs              CLI起動と終了コード
  cli.rs               引数の定義と検証
  app/                 画面遷移とユースケース
  domain/
    content.rs         正規化済み本文、ファイル単位、対象外理由
    dependency.rs      依存グラフからの純粋な打鍵順序計算
    typing.rs          I/O非依存の打鍵状態機械と計測
    progress.rs        行数ベース進捗集計の純粋ロジック
  source/
    local.rs           ローカルパスの解決
    git.rs             clone、キャッシュ、refresh
  scan/
    walk.rs            ファイル走査と自動除外
    extract.rs         正規化とファイル本文抽出
    language.rs        拡張子からの言語判定
    label.rs           行ラベルと設定フィルタ
    deps/              リポジトリ内importの抽出・解決
  store/
    sqlite.rs          スキーマ、進捗・セッション保存
  ui/
    terminal.rs        raw modeとalternate screenの生存期間
    home.rs            ホーム（ロゴ、Recent、Summary）
    search.rs          Searchモーダル用の候補生成
    splash.rs          引数あり起動時のスプラッシュ
    stats.rs           達成サマリ画面
    tree.rs            ファイルツリー
    typing.rs          写経画面
    result.rs          リザルト画面
    fx.rs              カーソル移動とブレイズ軌跡の演出状態機械
    highlight.rs       Typing本文の字句ハイライトと色配列
    theme.rs           Tokyo Night配色
tests/
  fixtures/            小さな疑似リポジトリ
  cli.rs
  repository_flow.rs
```

実装中にファイルを細分化してよいものの、責務と依存方向は維持します。

## 3. 依存方向

```text
CLI / UI ──► App ──► Domain
               ├──► Source
               ├──► Scan
               └──► Store

Source ──► Domain
Scan   ──► Domain
Store  ──► Domain
```

`domain`は`ratatui`、`crossterm`、`rusqlite`、`git`プロセス、実ファイルI/Oに
依存しません。`ui`はSQLiteやファイル走査を直接呼びません。

`ui::highlight`は正規化済み本文と相対パスを受け取り、表示用の文字インデックスに
対応する構文色配列を返します。syntectによる字句解析はTyping開始時に一度だけ
実行し、入力中に再解析しません。構文色は描画専用であり、`TypingEngine`、進捗、
永続化のデータモデルには入りません。言語サーバーは起動せず、未対応言語や解析
失敗時は単色フォールバックを使います。

## 4. 中心となる契約

実装開始時に統合担当が次の概念と公開境界を確定します。名前や詳細はRustで自然な
形へ調整できますが、責務を別モジュールへ漏らしてはいけません。

- `RepositorySource`: ローカルまたはGitキャッシュ上のルートを返す。
- `Scanner`: ルートを走査し、対象ファイル、対象外理由、正規化済みファイル本文を返す。
- `FileBody`（永続化では当面 `chunks` 表のファイルあたり1レコード）: 元ファイル、
  表示行範囲、正規化本文、SHA-256を持つ。
- `TypingEngine`: コマンドと時刻を受け、描画可能なスナップショットを返す。
- `ProgressStore`: リポジトリ、ファイル、ファイル本文、セッションを保存・復元する。
- `App`: Home / Search / Stats / Splash / Tree / Typing / Result の遷移と
  ユースケースを所有する。チャンク一覧画面は持たない。リポジトリ未ロード時は
  Home系画面のみを表示する。

打鍵エンジンへの入力は、文字、Enter、Backspace、Escape、時間更新へ正規化します。
エンジンは受理位置、期待文字、ミス表示期限、完了・中断状態、計測値を返します。

## 5. データモデル

MVPでは、少なくとも次の情報を永続化します。

- repository: 同一性、表示名、入力元、キャッシュパス、最終利用日時
- repo_file: repositoryとの関係、相対パス、自動対象外理由
- chunk: fileとの関係、正規化本文ハッシュ、表示行範囲、現在有効か
  （意味上はファイル本文。ファイルあたり常に最大1件のactiveレコード）
- chunk_progress: 完了状態と完了日時
- session: chunk（ファイル本文）、開始・終了、完了/中断、入力数、ミス数

ファイルやリポジトリの完了率は保存せず、完了ファイルの行数から集計します。
スキーマの列名とマイグレーション方式は実装時に決定し、`docs/decisions.md`へ
記録します。

## 6. 主要フロー

### 起動

1. 引数なしの場合、AppはHomeを開き、RecentとSummaryをStoreから読む。
2. 引数ありの場合、CLIがURLまたはローカルパスを検証し、Homeを省略する。
3. Sourceが利用可能なローカルルートを返す。
4. Scannerが対象判定とファイル本文抽出を行う。
5. Storeがハッシュで既存進捗を対応付ける。
6. AppがTree状態を構築し、UIを開始する（`--no-fx`でなければSplashを挟む）。

HomeのSearchはGitHub URL / `owner/repo`、またはローカルRecent・キャッシュ名の
あいまい一致だけを受け付ける。外部APIは使わない。

### ファイル完走

1. Treeでファイルを選ぶと、Appが正規化済み全文でTypingを開始する。
2. UIが端末イベントを打鍵コマンドへ変換する。
3. TypingEngineが入力を判定し、状態を更新する。
4. 完走時にAppがセッションとファイル完了を1トランザクションで保存する。
5. Appが行数ベースで集計し直してResultを表示する。
6. Esc / `t` / `r` でTreeへ戻ると更新済み進捗が表示される。EnterはHomeへ戻る。

### 中断

Escapeでは中断セッションだけを記録し、ファイル完了を更新しません。次回は
ファイル先頭から開始します。

## 7. エラーと安全性

- ユーザーが修正できる入力・設定・gitエラーには、原因と次の行動を表示する。
- 内部エラーでもpanicを通常の制御フローに使わない。
- cloneはアプリ管理下の確定したキャッシュパスだけへ行う。
- リポジトリ走査ではシンボリックリンクを既定で辿らない。
- `--purge`は削除対象を表示して確認を取り、管理ディレクトリ外を削除しない。
- 生の打鍵列は永続化せず、統計に必要な集計値だけを保存する。
- DB更新はトランザクションで行い、完了状態とセッションを食い違わせない。
- raw modeとalternate screenはRAIIガードで管理する。

## 8. 将来拡張

統計やPrepare画面などの残る機能も既存境界へ実装追加します。tree-sitterによる
ラベルとdependencyモードはD-016で追加済みです。MVPの打鍵エンジン、ファイル本文ID、
行数進捗集計を作り直さずに拡張できることを設計上の目標とします。
